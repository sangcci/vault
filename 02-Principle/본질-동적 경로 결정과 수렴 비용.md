# Principle: 동적 경로 결정과 수렴 비용

**핵심 질문**: 네트워크 경로가 바뀌었을 때 모든 장비는 얼마나 빨리 같은 판단에 도달하는가?

## 한 문장 정의

동적 경로 결정과 수렴 비용은 라우터가 장애나 토폴로지 변경을 반영해 경로를 자동으로 다시 계산하지만, 정확한 전체 지도 공유와 단순한 이웃 정보 전파 사이에는 확장성, 수렴 속도, 운영 복잡도 트레이드오프가 있다는 원리.

---

## 판단 기준

```text
Distance vector
  - 이웃이 알려준 거리 기반
  - 단순함
  - 수렴 느림, 규모 제한

Link state
  - 전체 토폴로지 지도 공유
  - 각자 최단 경로 계산
  - 빠른 수렴, 운영 복잡도 증가
```

---

## 실무 연결

백엔드 개발자가 RIP/OSPF 설정을 직접 만질 일은 드물다. 하지만 장애 상황에서 “패킷이 어느 경로로 가는가”, “네트워크 변경 후 왜 일부 구간만 잠시 실패하는가”, “라우팅과 NAT는 왜 다른가”를 이해하는 데 필요하다.
