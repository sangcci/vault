# Principle: 검색 품질과 생성 품질의 분리

**핵심 질문**: 답변이 틀린 이유는 검색이 틀렸기 때문인가, 생성이 틀렸기 때문인가?

## 한 문장 정의

검색 품질과 생성 품질의 분리는 RAG 시스템에서 관련 문서를 찾는 retrieval 단계와 그 문서를 바탕으로 답변을 만드는 generation 단계를 분리해 관측하고 개선해야 한다는 원리.

---

## 판단 기준

```text
Retrieval failure
  - 관련 문서를 못 찾음
  - 오래된 문서를 찾음
  - 비슷하지만 다른 문서를 찾음

Generation failure
  - 검색 결과는 맞지만 요약을 잘못함
  - 근거 없는 내용을 추가함
  - 출처와 결론을 잘못 연결함
```

---

## 실무 기준

- 검색 결과 topK와 score를 로그로 남긴다.
- keyword/vector/hybrid search를 질문 유형별로 나눈다.
- 검색 결과를 먼저 평가한 뒤 prompt를 튜닝한다.
- chunking, metadata, reranking을 별도 개선 지점으로 둔다.
- 답변에는 사용한 근거 chunk를 추적 가능하게 남긴다.
