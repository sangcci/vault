# Principle: 암호학적 무결성과 부인방지

**핵심 질문**: 데이터가 바뀌지 않았고 특정 주체가 서명했다는 것을 어떻게 증명하는가?

## 한 문장 정의

암호학적 무결성과 부인방지는 데이터 hash와 private key 기반 전자서명으로 변경 여부, 서명자 인증, 이후 부인 불가능성을 함께 제공한다는 원리.

---

## 해결하는 문제

- 전송 중 데이터가 변조되었는지 모르는 문제
- 메시지를 보낸 주체를 확인할 수 없는 문제
- 나중에 서명자가 “내가 하지 않았다”고 부인하는 문제
- PKI와 전자서명을 같은 개념으로 혼동하는 문제

---

## 판단 기준

```text
서명 생성
  message → hash
  hash + private key → signature

서명 검증
  message → hash A
  signature + public key → hash B
  A == B이면 유효
```

전자서명은 메커니즘이고, PKI는 그 public key가 누구 것인지 보증하는 인프라다.

---

## 진단 포인트

- 서명 대상 데이터가 정규화되어 있는지 확인한다.
- private key 보관과 rotation 정책을 확인한다.
- hash algorithm이 안전한지 확인한다.
- 검증 시 원문, signature, public key 신뢰 근거를 모두 확인한다.

---

## 트레이드오프

전자서명은 강한 무결성과 인증을 제공하지만 private key 보호에 실패하면 모든 보장이 무너진다. 긴 메시지를 직접 암호화하는 것이 아니라 hash를 서명해 성능과 입력 크기 문제를 해결한다.
