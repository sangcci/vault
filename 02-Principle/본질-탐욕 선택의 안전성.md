# Principle: 탐욕 선택의 안전성

**핵심 질문**: 지금 가장 좋아 보이는 선택이 왜 전체 최적해에도 안전하게 포함되는가?

## 한 문장 정의

탐욕 선택의 안전성은 각 단계의 지역 최적 선택이 어떤 전역 최적해로도 교환 가능하거나 전역 최적해의 일부임을 증명할 수 있을 때만 그리디 알고리즘이 정답을 보장한다는 원리.

---

## 해결하는 문제

- 반례 없이 감으로 그리디를 적용하는 문제
- 예제는 맞지만 숨은 테스트에서 최적해를 놓치는 문제
- 그리디와 DP 선택 기준을 “빠른 알고리즘 vs 느린 알고리즘”으로만 보는 문제
- 증명 없이 현재 선택이 미래 선택을 망치지 않는다고 가정하는 문제

---

## 판단 기준

```text
Greedy 가능성
  - 현재 선택이 최적해 일부로 교환 가능
  - 선택 후 남은 문제가 같은 구조
  - 과거 상태를 자세히 기억하지 않아도 됨

DP/탐색 필요 신호
  - 현재 선택이 미래 선택지를 크게 바꿈
  - 상태 기억이 필요
  - 작은 반례가 존재
  - 음수/보상/나중 이득이 있음
```

---

## 진단 포인트

- 선택 기준을 한 문장으로 명확히 쓴다.
- exchange argument 또는 greedy stays ahead로 증명한다.
- 작은 입력 brute force로 반례를 찾는다.
- 선택 후 남은 문제가 원래 문제와 같은 형태인지 확인한다.
- “현재 손해가 나중에 이득”인 구조가 있는지 본다.

---

## 트레이드오프

그리디는 빠르고 구현이 단순하지만, 그 단순함은 문제 구조가 현재 선택을 안전하게 해줄 때만 가능하다. 증명할 수 없다면 DP나 그래프 탐색처럼 더 많은 상태를 기억해야 한다.
