# Principle: 설정 우선순위와 출처 추적

**핵심 질문**: 최종 설정값은 어디서 왔는가?

## 한 문장 정의

설정 우선순위와 출처 추적은 여러 설정 source가 같은 key를 제공할 때 우선순위에 따라 최종 값이 결정되므로, 운영 안정성을 위해 값보다 출처와 검증 규칙을 명시해야 한다는 원리.

---

## 판단 기준

```text
Default config
  ↓ overridden by
Profile config
  ↓ overridden by
Environment variable
  ↓ overridden by
Command line argument
```

---

## 실무 기준

- 설정 source 계층을 줄인다.
- 중요한 설정은 origin을 로그로 남긴다.
- secret 값은 절대 평문으로 남기지 않는다.
- 필수 설정은 startup validation으로 fail-fast한다.
- 운영 override는 문서화한다.
