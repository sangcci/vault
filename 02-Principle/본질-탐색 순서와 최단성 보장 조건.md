# Principle: 탐색 순서와 최단성 보장 조건

**핵심 질문**: 먼저 발견한 경로가 언제 최단 경로가 되는가?

## 한 문장 정의

탐색 순서와 최단성 보장 조건은 그래프 탐색에서 어떤 노드를 먼저 처리하느냐가 최단성 증명과 직접 연결되며, 간선 비용 모델에 따라 FIFO queue, deque, priority queue가 달라진다는 원리.

---

## 해결하는 문제

- 가중치가 다른 문제에 BFS를 써서 틀리는 문제
- 최단 경로라는 말만 보고 알고리즘을 고르는 문제
- BFS의 O(V+E)와 Dijkstra의 O(E log V) 차이를 외우기만 하는 문제
- 우선순위 큐가 필요한 이유를 설명하지 못하는 문제

---

## 판단 기준

```text
모든 edge cost 동일
  - depth == distance
  - 먼저 발견한 경로가 최단
  - BFS + FIFO queue

edge cost가 0/1
  - 0-cost는 앞, 1-cost는 뒤
  - 0-1 BFS + deque

비음수 가중치
  - 현재까지 distance 최소 노드부터 확정
  - Dijkstra + priority queue

음수 가중치
  - 확정된 distance가 나중에 줄 수 있음
  - Bellman-Ford / DP / 문제 특화
```

---

## 진단 포인트

- 최단의 기준이 이동 횟수인지 비용 합인지 구분한다.
- 간선 가중치 범위를 확인한다.
- 나중에 발견한 경로가 더 짧아질 수 있는지 반례를 만든다.
- 방문 처리 시점이 enqueue인지 dequeue인지 알고리즘 조건과 맞는지 본다.

---

## 트레이드오프

BFS는 균등 비용이라는 전제 덕분에 정렬 비용이 없다. Dijkstra는 더 넓은 비용 모델을 다루기 위해 항상 현재 최소 distance를 선택하는 비용을 지불한다.
