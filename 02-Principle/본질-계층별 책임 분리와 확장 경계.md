# Principle: 계층별 책임 분리와 확장 경계

**핵심 질문**: 이 계층은 어떤 책임과 자원 특성 때문에 따로 확장되어야 하는가?

## 한 문장 정의

계층별 책임 분리와 확장 경계는 Web, WAS, DB처럼 서로 다른 책임과 자원 병목을 가진 부분을 분리해 보안, 확장, 장애 격리, 배포 유연성을 확보하는 원리.

---

## 판단 기준

```text
Web
  - 정적 파일
  - TLS 종료
  - reverse proxy
  - edge caching

WAS
  - 비즈니스 로직
  - 인증/권한
  - API orchestration

DB
  - 영속성
  - 무결성
  - transaction
  - query execution
```

---

## 실무 기준

- 계층 분리는 네트워크 비용을 감수하고 책임·보안·확장성을 얻는 선택이다.
- 작은 서비스는 단순한 구조로 시작해도 된다.
- DB는 계산 서버가 아니라 무결성과 영속성의 병목 자원으로 다룬다.
- WAS는 수평 확장하기 쉽도록 상태를 외부화한다.
- 외부 노출 계층과 내부 데이터 계층을 분리해 폭발 반경을 줄인다.
