# Principle: 사설 접근 경로와 권한 판단의 분리

**핵심 질문**: 네트워크에 들어왔다는 사실이 리소스 사용 권한을 의미하는가?

## 한 문장 정의

사설 접근 경로와 권한 판단의 분리는 VPN이나 터널이 private resource까지의 안전한 통신 경로를 제공할 뿐, 어떤 사용자가 어떤 리소스를 사용할 수 있는지는 별도 권한 모델로 판단해야 한다는 원리.

---

## 판단 기준

```text
Access path
  - VPN
  - Tunnel
  - Private subnet routing
  - Bastion host

Authorization decision
  - IAM
  - RBAC/ReBAC
  - DB account privilege
  - application permission
```

---

## 실무 기준

- VPN 접속 성공을 전체 내부망 신뢰로 해석하지 않는다.
- 자원별 최소 권한을 별도로 둔다.
- 환경별 네트워크 세그먼트를 나눈다.
- 접속 경로 로그와 리소스 접근 로그를 연결해서 본다.
- VPN 계정 탈취 시 폭발 반경을 제한한다.
