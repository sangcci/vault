# Deprecated: Phenomenon Note Rules

`02-Phenomenon/` 구조는 더 이상 사용하지 않는다.

증상, 에러, 병목, 장애는 새 구조에서 `01-Problem/` 노트로 작성한다.

예:

```text
기존: 02-Phenomenon/현상-커넥션 풀 고갈.md
현재: 01-Problem/01-외부 API 호출을 트랜잭션 안에 넣어 커넥션 풀이 고갈됨.md
```

새 노트 작성 규칙은 `Rule-Core.md`와 `00-Meta/Templates/Template-Problem.md`를 따른다.
