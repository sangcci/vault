# 동시성 문제를 설명할 때 용어 구분하자

## 용어들

- **동시성** : 여러 작업을 겹쳐서 다루기
- **병렬성** : 물리적으로 같은 시점에 실행되는 상태
- 경쟁 상태 : 실행 순서에 따라 결과 달라지는 문제 상황
- **원자성** : 하나의 작업 보장
- 임계 구역 : 경쟁 상태가 발생하는 영역
- **가시성** : 이미 쓴 값을 다른 스레드가 제대로 볼 수 있는지 여부(일관성과 관련)
- **격리** : 동시에 실행되는 작업이 서로 중간 상태를 얼마나 볼 수 있는지 보장(트랜잭션 격리, 트랜잭션 격리 수준)
- **트랜잭션** : 성공하거나 실패하는 하나의 작업 묶기

## 동시성 - 병렬성

한 일꾼이 여러 작업을 겹쳐서 다루기(멀티테스킹) - 여러 일꾼이 물리적으로 같은 시점에 다루기

## 격리 - 원자성

트랜잭션 원자성 - 업무 상태 전이의 원자성
트랜잭션 격리 수준을 통해 커밋 이전 상태와 이후 상태 값을 다른 트랜잭션이 읽을 때 보장할 수 있지만, 커밋 이전 상태를 읽어도 이 값을 Read-Modify-Write 까지의 절차에서 동시에 진행되서 잘못 읽을수도 있다.
