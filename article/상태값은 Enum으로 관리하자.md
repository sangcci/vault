# 상태값은 Enum으로 관리하자

여기서 말하는 상태값은 주문 상태, 유저 계정 상태를 의미한다. 결제 수단이나 유저 권한 같은 종류, 타입, 카테고리를 의미하지는 않는다.

흔히 회원의 회원 탈퇴 상태를 DB 컬럼 `is_deleted`로 관리한다. 하지만 회원 탈퇴는 생각보다 복잡한 정책을 가지고 있다. 단순히 컬럼으로 회원 탈퇴를 관리하기에는 나머지 정책을 구현할 때 햇갈릴 여지를 준다. 도메인 로직을 사용할 때는 괜찮은데, SQL문을 작성할 때 문제가 된다. 진짜 햇갈리기 때문.

`is_deleted`를 조회해서 회원이 삭제되었는지 판단한다. 단순히 2지 선다의 문제라면 사실 햇갈릴 여지가 없겠지만, 그렇지 않은 경우가 더 많다.
